# BC：VERA 超时子集与已完成子集的难度及探索性推算

统计快照：2026-11-13T18:34:17.358497+00:00。本分析未调用模型，没有把推算写回任何实测分数。

**结论：不能确认稳定的比例关系。** Hermes 的比例跨文本策略相差较大；DSH 的差异较小，但共同可比较的超时样本只有16题次，且换用各策略自己的可用子集会明显改变比值。下面的推算只用于敏感性分析，不可替代 rebuttal 主表中的实测 accuracy、avg3、标准差或显著性。

## 口径

- 题次为同一道题的一个 repeat；每组计划100题×3。按 question hash 和 repeat 配对，保留最早 completed，不依答案正确与否选择结果。
- S：VERA正常完成且已有有效判分。T：历史有明确 timeout 记录，至本快照仍未正常完成/判分；后续因系统故障 failed/not_started 的历史 timeout 仍属于T。明确任务预算耗尽的Z固定记0，不进入T。其余缺失/未评分为U。
- 每个 harness 的S*、T*分别取四个文本策略都有有效分数的共同子集。文本明确任务预算耗尽仍记0；系统错误、未完成和未判分不擅自补0。
- 下表是 pooled accuracy（正确题次/有效题次），不是三个repeat的mean±std。S*/T*由完成情况选择，存在选择偏差；三个repeat并非独立问题。

Hermes中Summarization两侧均最高、Discard最低，但No Compression与Sliding Window的次序发生变化；倍率0.122–0.554，不能用统一比例解释四种策略。DSH中Summarization仍最高，No Compression从高于Discard变为最低，倍率0.702–0.882，也不构成稳定比例关系的验证。

留一策略检验：用另三个文本策略的均值比例，预测被留下策略在T*上的准确率。Hermes的预测误差为−13.02、+20.93、+14.84、−23.87个百分点；DSH为+13.38、−3.87、−1.26、−8.34个百分点（顺序同表）。因此，即便文本方法之间，这个比例迁移也不可靠，更不能保证能迁移到视觉方法。

## 应用户要求给出的探索性推算

定义 k = 四种文本策略在T*上的平均准确率 / 在S*上的平均准确率；估算 VERA 的超时部分 p̂T = clip(VERA在S*上的准确率 × k, 0, 1)。全300估算为 (S中已测正确数 + |T|×p̂T + U中未知正确数) / 300，Z维持0。U取全错到全对形成端点；它不是置信区间。

|DeepSeek harness|VERA在S*的实测 %|k|超时部分估算 %|全300估算 %|按单个文本策略倍率推算的全300敏感性范围 %|加性模型全300估算 %|
|---|---:|---:|---:|---:|---:|---:|
|dsh|92.73|0.815|75.54|82.14–82.47|79.48–84.05|82.26–82.59|
|hermes|90.35|0.347|31.36|82.20|79.70–84.51|82.99|

Hermes的实测已完成部分为235/261；另37题次历史超时未恢复、2题次明确预算耗尽计0。DSH为189/206；另76题次历史超时未恢复、17题次预算0、1题次已完成待判分。因此DSH的82.14–82.47%仅由那1条未评分的取值形成，并非统计精度达到0.33个百分点。

加性模型改用 p̂T = clip(VERA在S*准确率 + 文本平均T*准确率 − 文本平均S*准确率, 0, 1)。单策略倍率与加性模型只是几种假设下的敏感性检查，不覆盖所有可能的缺失机制。

按100个问题簇重采样10,000次、保留三个repeat及可用性掩码，超时部分估算的条件bootstrap 95%范围为Hermes 17.71–48.04%、DSH 53.24–94.36%。该范围仅反映此固定推算规则的样本波动，不包含“文本难度比例能否迁移到VERA”这一假设错误，也不是已测VERA准确率的置信区间。

**适合rebuttal的表述**：VERA的超时子集在文本baseline下也明显更难，直接删除超时会产生乐观选择偏差；我们报告完成覆盖率、实测结果及探索性缺失结果敏感性分析，并继续恢复仍有尝试额度的任务。现有数据不支持把约82%的推算当作完整实验结果，也不支持声称已证明稳定比例关系。
