# RQ3 final seven-scale comparison

The requested scales are **0, 0.25, 0.5, 0.7, 0.75, 0.8 and 1**, each with the same 100 questions and three repeat labels. The final comparison contains 2,100 observations. Six scales reuse the existing repaired SFB campaign; only 0.75 runs in the new `rq3-deepseek-bc100-r3-scale0750-v1` campaign. Its other six placeholder cohorts are not admitted to this comparison.

`scripts/report_rq3_final_seven_v1.py --watch` writes `outputs/grading/rq3-final-seven-v1`. Its immutable `comparison-plan.json` binds both plans, cohorts, configurations, the user scope revision, the 0.75 authorization and the two fixed pre-native recoveries. The selected q085 / 0.8 / repeat 3 and q043 / 0 / repeat 1 recovery outputs replace their original unstarted observations; they do not create extra repeats or select an answer by score. The report also retains first-pass results.

Completed predictions use their existing isolated grade namespace. Confirmed terminal failures and missing observations follow the existing report convention; unavailable predictions or grades are never silently imputed as measured correctness. Before full coverage, the report gives known outcome counts, provisional accuracy and bounds using all 300 planned observations. Full avg@3, sample standard deviation across three repeat accuracies, question-cluster bootstrap 95% intervals, and six paired comparisons against 1x are released only with the required complete paired data. Holm correction covers all six comparisons. A nonsignificant difference does not establish equivalence. Repeat labels are not claimed to be independently seeded model runs.

Resolution applies to far history. At 0x, recent-history canvases are still retained. The report exposes measured compression counts separately; trajectories that never compress do not demonstrate an effect of resolution. Exposure-based subsets are descriptive, not randomized comparisons.

The removed 0.125 scale is excluded from accuracy and significance. Its raw prediction and judgment usage remains in `excluded-scale0125-cost.json`, with known token subtotals, missing-field counts, starts without a recorded return and unknown gateway prices. These costs are not transferred to the new 0.75 scale. The ledger does not claim to recover unreported SDK retries or provider charges.

`scripts/judge_rq3_final_six_ops1.py` uses the original six-scale grading root, protocol, lock, result bindings and request markers. It filters 0.125 before submission and checks the selection again before grading. The old judge was stopped with SIGTERM and drained before replacement; its completed grades and already dispatched calls remain intact. The 0.75 grader uses its own namespace. No scoring errors or unresolved requests are automatically retried by this scope change.

Validation: seven final-report tests cover the exact 1,800+300 mapping, fixed recoveries, source binding, missing coverage, clustered inference and unknown cost accounting. Three grading-wrapper tests cover strict scale selection, unchanged grade delegation and rejection after a scope-source change. Creating reports and testing these wrappers makes no model calls.
