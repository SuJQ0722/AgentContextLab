# 所有方法共同完成集合：全实验结果快照

生成时间：2026-11-11T04:03:45.968352+00:00

主实验模型为 DeepSeek-v4.1-flash-1017，四条获准渠道的恢复记录保留。以同一题目内容、同一 repeat 配对，先取全部方法正常 completed 的交集，再排除任一方法缺少有效评分的整组。成功结束允许途中故障后恢复，不等于全程零错误。没有按答对筛题；已完成的错误答案保留。明确排除按答案正确性选择的 BC/MMBC bounded 重跑。

这是成功完成条件下的准确率，不能代替完整100×3准确率或证明总体优越性。下列共同题次的 repeat 覆盖不齐，因此先报题次等权准确率；只有严格三repeat齐全子集才报avg3±std。工程恢复涉及不同渲染/传输版本，不冒称同协议的新独立实验。
